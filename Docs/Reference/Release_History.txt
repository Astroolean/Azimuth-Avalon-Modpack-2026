HOW RANDOM FINISHES WORK
The default is a 20% chance for each compatible item. Skins/Camos lets you
turn random skins off or choose a different percentage. Save changes while
the game and server are stopped, then use Play Avalon to apply them.

The system checks firearms, melee weapons/tools, magazines and compatible
stocks, handguards, suppressors and other weapon parts from the loaded game
and mod pack. It uses the body's exposed retexture selections. Models with
no safe paintable surface stay unchanged. Optics, loose ammo, alpha-cutout
surfaces and ghillie wraps are excluded. This is broader than M4A1/AKM, but
it cannot create paintable surfaces that a model does not provide.

Existing saved items can receive finishes when they load, as can new loot.
The same item keeps the same result across restarts with unchanged options.
Changing the chance or selected finishes can change existing random finishes.
Parts receive their own chance, so a gun and its magazine need not match.
Only checked finishes are included. No replacement gun or extra loot spawn
is created; normal classes, ammunition, attachments and statistics remain.

The existing fixed Azimuth M4A1/AKM and showcase guns retain their explicit
finishes. Unchecking one of their finishes removes its classes as before;
keep a finish selected while you own fixed variants that use it.
Turning off random skins returns ordinary randomly painted items to their
normal appearance after restarting. A world wipe is not required.

PHOTO CONTROLS
P              Enter / leave photo camera
W A S D        Move camera forward / left / back / right
Q / E          Move down / up
Mouse          Look around
Mouse wheel    Zoom in / out
Left Shift     Move faster
Left Ctrl      Move slower for close angles
F12            Take a Steam screenshot (Steam's default shortcut)

P controls the camera; it does not save an image. The camera stays within
20 metres of your character. Your character stays in place while the
camera moves; the world keeps running. This mode adds no protection or
pause. Exit restores your prior perspective, HUD and normal controls.
Opening a menu or leaving a supported character state ends photo mode.

Rebind P in Options > Controls > Azimuth photo mode; I is under Azimuth.
I still inspects the gun in first person: stand still with aim released,
then tap I. Tap I again, move, aim, fire or reload to stop the inspection.

AZIMUTH
DayZ Server Manager
Created by Ashton Kenney
Windows 10/11 • DayZ on Steam

PLAY AVALON
1. Extract the ZIP and double-click START_SERVER.bat inside Azimuth.
2. Close DayZ and its launcher if they are open. Click Play Avalon.
3. The first time, approve any Steam installs and click Subscribe on the
   Workshop pages Azimuth opens. Leave Azimuth open while they download.
   Once Steam finishes, Azimuth prepares the pack and joins automatically.

For distance and image quality in one click, use Client > Play Avalon
Enhanced. It selects the Avalon Visuals quality preset: 5,000 m terrain,
3,000 m objects, more detail, and cleaner edges. It also enables the
daylight color preview and joins Avalon. If Avalon is running without it,
Azimuth waits for it to be empty and performs a clean restart. The first
time, approve DayZ Tools in Steam if it is needed for signing.

Azimuth waits for Steam, signs Hunter Mods, starts Avalon, and then launches
DayZ through BattlEye with the same client mods, address and password. It
applies your saved graphics preset to the selected DayZ profile.
Azimuth matches DayZ's Windows access level to Steam. If Steam itself is
running as administrator, Windows may ask for approval to launch DayZ.
Activity reports how many mod paths reached DayZ when the client writes a
new launch log. The Windows Avalon server and client use matching short
links to the original mod files. If Steam changes those files during
startup, Azimuth waits for an empty Avalon, restarts it, and then joins.
Azimuth reuses your saved graphics profile or identifies one from your
DayZ client logs and existing profiles. If it cannot identify the profile,
Play Avalon still launches DayZ. The preset applies on a later launch
once Azimuth identifies the profile. Client > Choose profile lets you
select a different profile manually.
To cancel before launch, click Stop. If a Steam prompt was dismissed,
click Play Avalon again to reopen it.

BACKUPS AND RESTORE
Every world has its own Backups folder. A backup is due six hours after
its first launch or last completed backup. Azimuth waits until the active
server has been empty for a minute, stops it normally, checks the shutdown
log, verifies the backup ZIP, and restarts the world. Keep Azimuth running
to service its backup schedule. Closing the window minimizes it.

Before restoring, stop DayZ and click Exit Azimuth. Move the world's
current World and Profiles folders aside, then extract its backup into
the corresponding world directory. For Chernarus+ that is Azimuth itself.
For Avalon that is Azimuth/Worlds/avalon. The other world directories are
Azimuth/Worlds/livonia, Azimuth/Worlds/deer_isle, and Azimuth/Worlds/namalsk.
A modded world also needs the same mods installed. Backups contain the
join password and other settings. Keep them private.
For Avalon's Workshop pack, keep its Config/avalon-workshop.json from
the same backup as the World and Profiles directories. The pre-pack backup
has no pack marker. Move the current marker aside when restoring that backup.

PLAY WITH SOMEONE ELSE
They need Steam DayZ and the same mods for the active map. A second PC
joining Avalon needs the same signed local @HunterMods folder. On the same
network use the address shown in Azimuth. For internet play, the host needs
a reachable public IPv4 or a shared private network. With public IPv4,
allow the server through Windows Firewall and forward UDP 2302, 2304,
and 27016 to the host PC, or their configured equivalents.
