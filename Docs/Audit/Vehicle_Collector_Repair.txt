CORRECTION
- Workshop sources are processed first. Native archive prefixes are checked
  before indexing, so unrelated sound archives do not consume the member budget.
- Each source has a bounded allowance alongside aggregate safety limits.
  Errors and incomplete scans are recorded per source instead of silently
  appearing to be a complete search. Actual header bytes are accounted for.
- Requested models, textures and materials are prioritized. Identical resource
  payloads are stored once while preserving the source records and hashes.
- LM's original archive can go in a companion ZIP when it cannot fit beside
  the other assets. Each ZIP remains at most 500 MiB. An LM archive above the
  400 MiB raw-file bound gets explicitly labelled header/tail diagnostic data,
  never a falsely complete archive. Its actual size is recorded.
- Each collection is published in a new folder only after its files are ready.
  Failed copying or companion creation cleans up the entire unfinished output.
- The control panel shows the actual collected count, incomplete scans and
  size limits. When there are two ZIPs, it tells you to send both together.
