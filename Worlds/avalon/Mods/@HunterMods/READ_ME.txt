HUNTER MODS FOR AVALON
All eight mods are by Hunter Mods, from the ZIP supplied for this server.
https://huntermods.online/

This folder is both the local client mod and Avalon's server mod.
Azimuth signs it with DayZ Tools and registers its mission economy.
In the DayZ Launcher Mods tab, add this folder as a local mod and enable
it together with Avalon and Community Framework.

The server generates default Hunter Mods settings in Worlds/avalon/Profiles.
